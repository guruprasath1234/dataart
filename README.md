# My Timeline App

## Task 1: Static Skeleton

This is the initial structure of the **My Timeline** web application. It lays out the basic HTML framework without any dynamic functionality or styling. This version focuses on setting up key components to support future development.

---

### 📦 Included Features:

- **Header**: Contains a logo and a theme toggle button.
- **Navigation (`<nav>`)**: Placeholder area for future filters or controls.
- **Main Timeline Section**:
  - A list of sample timeline years (1990, 2000, 2005, 2015) for structure.
  - An empty area where timeline events will be dynamically added in future stages.
- **Image Placeholder**: Displays a timeline banner image.
- **Modal Container**: Reserved for pop-ups or overlays to be implemented later.
- **Footer**: Basic copyright notice.
